# ⭐ React Star Rating Component

A simple and interactive star rating component built with React and react-icons.

---

## 🚀 Features

- Dynamic star rating
- Hover preview effect
- Customizable colors
- Reusable component
- Responsive UI

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/techbyusmandev/star-rating-react-component.git
```

Move into the project folder:

```bash
cd star-rating
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
